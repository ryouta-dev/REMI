# REMI

Демо-сайт кафе и ресторана в Семее. Статические HTML, CSS и JavaScript, сборка и серверная часть не требуются.

## Локальный просмотр

В каталоге проекта запустите `python -m http.server 8080` и откройте http://localhost:8080. Используйте HTTP для загрузки файлов меню и настроек.

## Редактирование

- `menu.json` содержит 17 категорий и 89 позиций. `prices` — массив цен в тенге в порядке печатного меню. При отсутствии цены оставьте `[]`, при отсутствии описания — пустую строку. Необязательное поле `image` указывает имя изображения без суффикса ширины и расширения.
- `restaurant.json` содержит контакты, историю, особенности, настройки витрины и поля для будущих отзывов и канала бронирования. Заполните `popularDishes` точными названиями из меню, когда ресторан подтвердит подборку.
- `assets/` содержит WebP из фото интерьера и пяти фотографий на странице «Восточные блюда» печатного меню. Фото расположены в том же порядке, что и позиции. Привязку стоит подтвердить у ресторана.
- Два значения цены лимонадов переписаны в порядке источника. Объём каждой порции в печатном меню не указан. Самостоятельных описаний блюд нет.

## Публикация

На GitHub Pages разместите файлы в корне ветки и выберите её и папку `/ (root)` в Settings → Pages. Для Netlify можно загрузить папку с `index.html` через ручное развёртывание. После получения URL замените `og:image` в `index.html` на абсолютный адрес изображения.

Кнопки бронирования открывают WhatsApp с готовым текстом. Гость отправляет сообщение и договаривается с кафе в чате. Номер и текст меняются в полях `whatsapp` и `whatsappMessage` файла `restaurant.json`.
